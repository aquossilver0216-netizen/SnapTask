# SnapTask｜提出前チェックリスト

## 公開前

公開先の具体的な設定は [`docs/release.md`](release.md) を参照する。

- [ ] 一般ユーザーがアクセスできる公開URLを用意する
- [ ] スマートフォン（Safari / Chrome）でトップページを開く
- [ ] `pnpm run build` が成功する
- [ ] `pnpm run lint` が成功する
- [ ] `pnpm test:smoke https://公開URL` が成功する
- [ ] `https://公開URL/api/parse` を開き、`ok: true` のヘルスチェックを確認する（APIキーの値は表示されない）
- [ ] 公開環境の環境変数に `GEMINI_API_KEY` を登録する（キーをソースコードへ書かない）
- [ ] Gemmaモードを使う場合は、デモ端末でBionic / LM Studioの `http://127.0.0.1:1234/v1` を起動し、追加・暗記画面の自動接続確認で「接続中」を確認する

## 90秒デモ

1. ホームの「3ステップ」を見せ、課題が2件ある状態から始める。
2. 「プリント・黒板を撮る」→複数写真を選ぶ。
3. AI結果の課題名・教科・締切・やることを1か所編集する。
4. 保存してホームへ戻り、締切までの残日数を見せる。
5. チェックを付け、今週のペースと連続日数が変わることを見せる。
6. 学習カレンダーの日付をタップし、課題・テスト・ミスの内訳を見せる。
7. 「暗記」→「一周学習」→カードをめくる→「覚えた」→結果画面まで進む。
8. 「4択テスト」→結果→「まちがい」復習まで進む（カード4枚以上）。
9. 「カードを整理」でカードを別の単語帳へ移動できることを見せる。
10. 「共有」→暗記ページを選択→共有シート／共有リンク／ファイル保存まで見せる。受け取ったJSONまたはリンクの取り込み口も確認する。
11. AIを使えない場合は「写真がなくても試す（サンプル）」、前回データが残っている場合はホームの「デモに戻す」を使う。

## 発表で必ず伝えること

- 課題の写真・黒板・教材がバラバラで、締切と勉強内容を覚えておく負担を解決するアプリであること
- AIの結果をそのまま保存せず、必ず確認・編集してから使えること
- Gemmaのローカル処理とGemini APIを切り替えられること
- 課題の完了、暗記テスト、間違い復習、7日間の記録まで一つにつながっていること
- データは端末保存が基本で、バックアップ保存・復元もできること
- 暗記ページは共有データとしてコピー・保存でき、友だちのJSONを取り込めること
- Gemma停止時もGemini APIへ切り替えてデモを継続できること

## 注意

AIの読み取り結果は必ず画面で確認する。特に締切・数式・英単語の綴りは、デモでも編集欄を一度見せる。
