# SnapTask｜テック甲子園向けデモメモ

## ひとことで

プリントや黒板を撮るだけで、提出物を「締切順のToDo」に変える高校生向けアプリ。さらに、教材写真から暗記カードも作り、提出物とテスト勉強を一つの場所で続けられる。

## 解決する困りごと

高校生は、課題が複数のプリント・黒板・連絡に分散し、「何を、いつまでに、どこまでやるか」を覚えておく負担が大きい。SnapTaskは写真を入口にして、入力の手間をなくし、締切と進捗を毎日確認できる形にする。

## 90秒デモの流れ

1. ホームで「未完了」「今週締切」「連続日数」を見せる。
2. 「プリント・黒板を撮る」から複数枚の写真を選ぶ。HEIC/JPGは自動でPNGに変換される。
3. AIの読み取り結果を確認し、課題名・教科・締切・やることをその場で修正して保存する。
4. 課題を完了にすると、今週のペースと7日間の記録が更新される。日付をタップすると、その日の課題完了数・テスト数・ミス数を振り返れる。
5. 「教材を暗記カードにする」で教科別の暗記ページへ移動し、写真または手入力でカードを追加する。
6. 4択テストを一周して正答率と間違いカードを確認し、Gemmaが止まった場合は画面上のボタンからGemini APIへ切り替える。

## 受賞作から取り入れた考え方

- 写真から成果物までを一気通貫にする（WordCam / Neureka!）
- 学習の変化を数字と日別の記録で見えるようにする（WordCam / スタレコ）
- AIが勝手に決めた結果をそのまま保存せず、ユーザーが確認・編集できるようにする
- 課題完了と暗記テストを同じ日別カレンダーに記録し、学習の変化を振り返れるようにする
- Gemmaのローカル処理とGemini APIを切り替えられ、用途に合わせて技術を説明できるようにする

## 技術の見せ場

- ブラウザ内で画像を正規化し、HEIC/JPGをPNGに変換
- `Gemma（Mac内）` と `Gemini API` を同じ画面から切り替え
- AIの出力をJSONとして受け取り、課題・暗記カードを編集可能なデータに変換
- データはまず端末のlocalStorageに保存。ログインなしでもすぐ試せる
- Gemmaモードでは写真を外部APIへ送らない構成を選べる
- 発表前に「デモに戻す」で課題・カード・学習ログを確認付きで初期化できる

## 発表で伝える注意点

AIの読み取りは必ず確認画面を通し、締切や課題名をユーザーが直せることを見せる。大会デモではサンプル画像を用意し、撮影→確認→保存→完了→振り返りの流れを止めずに見せる。
